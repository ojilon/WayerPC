# 03 — Frontend (Wails + Vite + TS + HTML + CSS, frameless)

Toolchain: **pnpm** + **Vite** + **TypeScript** (strict). No framework:
hand-rolled views keep the bundle tiny and the frameless shell fully owned.
`wails.json` sets `"frameless": true`; all chrome is custom.

## Layout (`frontend/`)

```
frontend/
├── package.json (pnpm scripts: dev/build/preview/typecheck)
├── vite.config.ts (root src, out dist, version-define from version.json)
├── tsconfig.json (strict, noUnusedLocals)
├── index.html (mounts #app, links styles.css)
└── src/
    ├── main.ts (boot, titlebar wiring, router, wails-ready wait)
    ├── styles.css (dark tokens, layout, titlebar, tabs, tables, dialogs)
    ├── api.ts (typed wrapper over window.go.main.App.* + browser mock)
    ├── dev-mock.ts (fake data when window.go absent: wails dev/browser)
    ├── version.ts (GENERATED by scripts/sync-version.mjs — do not hand-edit)
    ├── views/console.ts (status hero, network stats, live log, start/stop)
    ├── views/import.ts (search bar, progress, tick-list, import selected/all,
    │                     browse files/folder via Go dialogs)
    ├── views/library.ts (Received ⇄ Imported catalog switch, remove,
    │                      reveal-in-explorer, refresh)
    └── views/settings.ts (data-root picker + relocate, host/port, version,
                           storage sizes, open data folder)
```

## Frameless shell

- Custom titlebar: app dot + name + version chip left; search-path hint
  center; `_` / `▢` / `✕` right. Region uses `--wails-draggable: drag` so the
  window moves; buttons are no-drag and call
  `WindowMinimise / WindowToggleMaximise / Quit` (via `api.ts`, with
  `window.runtime` fallback).
- `wails.json` also sets min size 960×600, `windowresizable: true`,
  dark `theme: system`-independent background `#0f1419` to avoid white flash.
- No native menu; keyboard: `Ctrl+1..4` switch tabs, `Ctrl+L` clear log.

## Redesign vs legacy CustomTkinter (improvements, not a copy)

- One persistent left nav (Console / Import / Files / Settings) instead of
  open-ended `+` tab spawning; Import/Files support **multiple pending
  searches as stacked result cards** without window clutter.
- Console merges status + stats + log with pause/autoscroll/filter
  (legacy had no filter/pause and polling overwrote text).
- Import rows show size + modified + parent folder, checkbox tri-state,
  `Import selected/all`, progress bar for big walks, empty/error states.
- Files view segments `Received | Imported catalog | Shared`, each with
  sort (name/size/modified), per-row `Reveal` + `Remove` (catalog only),
  missing-on-disk badges (legacy only appended text).
- Settings is new: data-root chooser/relocate, host/port display, version +
  protocol version, storage usage, `Open data folder`, danger-zone
  `Relocate` with confirm. Legacy buried this in startup CLI prompts.
- Global toast + confirm-dialog components; all strings in one place for
  future i18n. Responsive ≥960px, focus-visible outlines, aria labels.

## Wails wiring

- `api.ts` declares `declare global { interface Window { go?: any } }` and
  exposes `isWails()`, `call<T>(name, ...args)` → `window.go.main.App[name]`,
  plus `onEvent(name, cb)` subscribing to `window.runtime.EventsOn` when
  present (else no-op mock). `wails dev` injects `window.go`/`window.runtime`;
  plain `vite dev` uses `dev-mock.ts`.
- Go pushes: `log` (append), `stats` (1s snapshot), `catalog-changed`
  (re-list), `search-progress` (import progress bar).
